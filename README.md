# Velvet Sound

Site oficial da **Velvet Sound**: música ao vivo para casamentos, cultos e festas em Barueri/SP e região.

🌐 **[velvetsound.com.br](https://velvetsound.com.br)**

## Sobre

Landing page responsiva em HTML, CSS e JavaScript puro, num único arquivo (`index.html`), com:

- Galeria de fotos com ampliação em tela cheia
- Orçamento rápido que gera a mensagem pronta no WhatsApp
- Painel de acessibilidade arrastável (tamanho de texto, alto contraste, fonte legível, espaçamento, guia de leitura, leitura em voz alta e mais)
- Tradutor de Libras (VLibras)
- Botão flutuante de WhatsApp
